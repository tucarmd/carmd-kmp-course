Remember

  • StateFlow is conflated: collectors see the latest value, not every value. Use it for state, not for one-off events.
  • A struct copies, a class shares. Data is a struct; things with identity (scanners, adapters) are classes.
  • A scope owns its coroutines: cancel the scope and its work stops. Swift's bare Task { } has no such owner.
